# 交易技術指標研究

- 先問現有策略哪個環節需要改善，從進場、行情篩選、出場、部位控制中選擇對應環節。比較不同資訊來源，或把同家族公式當作替代方案。例如 RSI、KD 與 Williams %R 同屬價格動能，三者同向仍可能只反映同一次漲跌。
- 依 [技術指標選用與公式](references/technical-families.md) 找候選及失效情境。查全部 TA-Lib 函式代號時讀 [官方函式索引](references/ta-lib-index.md)。平台特有或同名異式的指標，回到供應商公式、版本及資料範例核對。
- 為每個候選記錄價格欄位、頻率、長度、單位、平滑方式與種子、資料缺值及零分母處理、第一根有效值、訊號可用時點、委託可執行時點。前一棒與當棒各自代表不同交易條件。
- 實作前先用同一段人工資料比對逐棒輸出，再用真實行情檢查交易。若指標需要未完成高週期棒、事後確認轉折或非標準 K 線，先定義可觀測時點及可成交價格。檢查結果時以實際引擎與版本為準。
- 工作台的候選設計、PL 支援範圍、MCP 比較與樣本外驗證可使用 `strategy-optimization`。委託簿、跨商品、未平倉量、波動率指數及法人籌碼可使用 `futures-market-indicators`。
