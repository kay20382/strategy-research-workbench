# 策略研究工作台

在 Windows 雙擊 `PL回測工作台.cmd`。`行情資料管理.cmd` 會啟動同一套軟體，並直接顯示行情資料庫。

外部助理可透過 MCP 查詢行情與策略、執行回測，並提交候選 PL 比較績效。 [MCP 連線設定](strategy-studio-mcp.md)

1. 在「行情資料庫」管理商品、匯入及匯出 Tick／1 分 K／日 K，或檢查資料缺漏。選擇商品後，可用「帶入回測」把已確認的商品規格和行情來源帶到目前策略。
2. 在「程式碼撰寫」匯入、貼上或編寫 PL 策略，以 F7 檢查相容語法。用 Ctrl+S 將草稿存入策略庫。
3. 在「回測」確認期間、週期、交易成本和暖機棒數。以 F5 開始回測，在回測結果頁查看逐筆交易、權益曲線、HTML 或 Excel。
4. 在「AI 優化」填寫修改目標，選擇以已平倉淨利或最大回撤排序，設定 1～5 輪。OpenAI API 金鑰可在畫面輸入，也可從啟動程序的 `OPENAI_API_KEY` 讀取。模型預設為 `gpt-5-mini`，可在畫面修改或透過 `STRATEGY_OPENAI_MODEL` 設定。

AI 優化先回測原版，再逐輪產生候選 PL。每輪使用本機引擎檢查及回測，下一輪會參考實際結果或語法錯誤。工作台核對行情雜湊、實際回測設定、相依函式及引擎。選取通過回測的候選版，可以並排查看程式碼、開啟回測報表或另開草稿。原版和候選版的原始碼、設定及報表各自存於 `outputs/pl-workbench` 的執行資料夾。

排名反映本次回測期間的已平倉淨利或最大回撤，尚未包含樣本外驗證。AI 請求會將策略程式碼、優化目標、績效摘要、部分回測設定及語法錯誤傳至 OpenAI。金鑰欄位只在目前工作台程序內使用。 [OpenAI Responses API 文件](https://developers.openai.com/api/reference/resources/responses/methods/create)
